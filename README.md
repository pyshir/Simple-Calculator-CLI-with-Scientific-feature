# Simple Calculator CLI

A lightweight command-line calculator built with Python that supports both basic arithmetic operations and essential scientific calculations. The project also saves calculation history to a text file for future reference.

## Features

### Normal Mode

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Modulus (%)
* Multiple number addition
* Multiple number multiplication

### Scientific Mode

* Square Root (√)
* Power (x^y)
* Sine (sin)
* Cosine (cos)
* Tangent (tan)

### Additional Features

* Input validation
* Calculation history saved to `history.txt`
* User-friendly CLI interface

## Technologies Used

* Python 3
* `math` module
* `inflect` module

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/simple-calculator-cli.git
```

2. Navigate to the project directory:

```bash
cd simple-calculator-cli
```

3. Install dependencies:

```bash
pip install inflect
```

4. Run the program:

```bash
python calculator.py
```
